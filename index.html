DistroHopper39B's Website

Hello, I am DistroHopper39B, or Distro for short! I'm a high school student from New York who loves low-level programming and technology as a whole. I've been making YouTube videos for over ten years, and I've been messing with computers for about eight. I'm particularly interested in computers from the 2000s and 90s, which is the primary content on my channel. This website is designed to load on vintage computers (mostly using ancient HTML and CSS features and allowing non-SSL connections) though it will look better on newer browsers with support for fonts (do report issues if there's any problems with this site on older browsers as I don't test consistently).

I'm most well known for NTATV, my port of Windows onto the original Apple TV that has been featured by Snazzy Labs, Michael MJD, Nobel Tech, and UFD Tech, among other channels.

I currently own upwards of 40 computers that have been variously acquired from friends, family, swap meets, thrift stores, and in a few cases from the side of the road. No, I don't have a problem. I can stop whenever I want.

Programming Projects

  • NTATV: Windows NT (2000/XP/2003/ReactOS) port to the original Apple TV
  • ATV1sm: Bypass for the original Apple TV's EFI verification, allowing it to boot and run any EFI-capable OS.
  • Boot2TargetDisplay: Boot straight to Target Display Mode, without booting Mac OS, on supported iMac models
  • GopShim: Adds UEFI Graphics Output Protocol (GOP) support to early Intel Macs with no GOP support, allowing them to boot more OSes (such as modern Windows) in UEFI mode
  • atvlib (GitHub): Apple TV 1st Generation example code
  • U-Boot Stub for Apple TV (GitHub): Stub to allow my modified (but only to fix bugs) version of U-Boot to run on an original Apple TV, allowing for execution of arbitrary UEFI executables (old method), and therefore Windows 8 and later (provided your TV has been upgraded to 512MB RAM).
  • atv-linux-loader (GitHub): Modern Linux bootloader for the original Apple TV

Other, usually incomplete projects I've done can be found on my GitHub account.
