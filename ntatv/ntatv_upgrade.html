Upgrading from previous NTATV releases to release 1.1

NTATV version 1.1 is a major codebase upgrade and, thanks to work by ReactOS developers, is much closer to upstream ReactOS. However, a change in ReactOS' FreeLoader slightly changed the way video information is passed through to Windows, just enough to break the existing bootvid.dll and genfbvmp.sys drivers that allow the Apple TV to display basic video and a boot screen under Windows. Upgrading these drivers is necessary in order to preserve a working boot screen and basic video.

Steps to do this without removing the hard drive:

  1. Copy the contents of the ntatv_drivers_and_utils_1.1.iso to a FAT32-formatted USB flash drive.
  2. Boot the Apple TV into Windows
  3. Copy freeldr.sys from the Boot directory in the ISO to the boot partition on the Apple TV.
  4. Run genfbvmp_1.0.2_installer.exe from the Drivers directory.
  5. Reboot the Apple TV.
    • After a reboot, Explorer might not launch. To fix this, press Control-Shift-Escape to open Task Manager, kill nvsvc32.exe and explorer.exe, go to File -> Run, then type explorer.
  6. Install the NVIDIA drivers from NVIDIA_179.48_AppleTV.exe
  7. Reboot the Apple TV again
  8. Display Properties will erroneously claim that the NVIDIA drivers are not running. To fix this, reboot the system for a third time.

On Windows 2000, you will also need to edit C:\freeldr.ini and change the BootType from Windows to Windows2000.
